# 2026-10-04: 0.1.1 배포 전 다듬기 완료

이전 핸드오프(`2026-10-02-v01-complete.md`)를 대체한다. 특히 그 문서의 F5 절차에
있는 "`salvo.yaml`에 `schema: url:` 두 줄 추가" 단계는 **이제 따르면 안 된다.**
quickstart 매니페스트에 이미 `schema`가 있어서 키가 중복되고 매니페스트 오류가 난다.

## 무엇을 했나

| 항목 | 내용 |
|---|---|
| quickstart | 데모 API 스키마를 로컬 SDL(`examples/quickstart/countries.graphql`)로 동봉. MIT 고지 전문을 파일 머리에 포함. 예제가 스키마 기준 오류 0건임을 테스트가 보장하고, 깨진 예제는 잡히는지도 테스트한다 |
| 마켓 표시 | 사용자 결정으로 범용 API 테스트 도구로 포지셔닝. 설명에는 현재 지원 범위(GraphQL over HTTP)를 그대로 적었다. `rest` 키워드는 v0.3 HTTP 전면 지원 때 넣는다(`roadmap.md` 위험 7) |
| 저장 단축키 | Cmd/Ctrl+S를 누르면 입력칸이 포커스를 잃지 않고 바로 확정된다. 확정한 값의 응답이 돌아와도 그 사이 입력한 글자를 덮지 않는다(`src/webview/echo.ts`, 포커스가 있을 때만 동작). 한글 입력기 상태에서도 물리 키로 인식한다 |
| CI | `.github/workflows/ci.yml`: Node 20과 22에서 check, gen:check, test, package. 시크릿을 쓰지 않는다. `test:vscode`는 디스플레이 서버가 필요해서 넣지 않았다 |

검증: main 머지 후 vitest 169개 통과, check와 gen:check exit 0, vsix 16파일
549KB(소스맵 없음). 실제 VS Code 스모크 2개 통과는 머지 직전 브랜치에서 확인했다.

## 배포 전 F5 확인 (사람)

`examples/quickstart/countries.salvo`를 열고 `Salvo: Open Visual Editor`를 실행한다.
매니페스트는 고치지 않는다.

1. 툴바가 `schema: ready`를 보여 준다.
2. Run all cases를 누르면 두 점이 초록이 된다.
3. URL을 고치면 옆의 텍스트 에디터에서 그 줄만 바뀐다.
4. 쿼리에 없는 필드를 쓰면 물결 밑줄이 보이고, 필드 이름을 칠 때 자동완성이 뜬다.
5. 입력 중 Cmd+S를 누르면 커서가 그 자리에 남고, 입력이 파일에 들어간다. 저장이
   먼저 끝나면 한 번 더 저장해야 할 수 있다(순서 미확인).
6. 확인하면서 README용 스크린샷 2장(실행 결과, 자동완성 팝업)을 찍는다.

  뜨지 않는다. 포커스가 없는 동안 도착한 응답은 항상 파일 값을 따른다.
